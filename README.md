# FMCS-B737 — privacy policy, terms of use and support

The page published at <https://gokku.github.io/fmcs-b737/> for the iOS app
**FMCS-B737** (bundle `ee.addie.FMCS737`, ADDIE OÜ).

`index.html` is the same file the app bundles at `FMCS737/Resources/Legal/legal.html`,
so the page a user reads inside the app and the page linked from the App Store listing
cannot drift apart. Change it in the app repository first, then copy it here:

```bash
cp ~/Projects/FMCS737/FMCS737/Resources/Legal/legal.html index.html
```

Anchors used by the listing and by the app: `#privacy`, `#terms`, `#support`.
